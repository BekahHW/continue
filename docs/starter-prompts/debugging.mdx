## 🔴 Critical Errors

### Fix Runtime Exceptions

<Tabs>
<Tab title="Prompt">
```
I'm getting this error: [paste error message]

In file: [file path or @File reference]

Please:
1. Identify the root cause
2. Explain why it's happening
3. Show me the fix with code
4. Explain how to prevent this in the future
```
</Tab>
<Tab title="Best Practices">
**When to use:** Any runtime error or exception

**Mode:** Chat → Edit/Agent (for fix)

**Pro tips:**
- Include the full stack trace
- Mention when the error occurs (on load, on click, etc.)
- Add relevant context with @CurrentFile or @File
</Tab>
</Tabs>

## 💡 Pro Debugging Tips

<AccordionGroup>
  <Accordion title="Include Context" icon="layer-group">
    Add relevant context to your debugging prompts:
    - `@CurrentFile` - Current file
    - `@Terminal` - Error output
    - `@Diff` - Recent changes
    - `@Commits` - Recent commits

    **Example:**
    ```
    This error started after my recent changes:

    @Diff
    Error: @Terminal

    What did I break and how do I fix it?
    ```
  </Accordion>

  <Accordion title="Use Bisect Approach" icon="code-branch">
    For hard-to-find bugs:
    ```
    I have a bug but don't know where it is.

    Please help me bisect:
    1. Review recent changes (@Diff)
    2. Identify likely culprits
    3. Create a testing strategy
    4. Narrow down the source
    ```
  </Accordion>

  <Accordion title="Add Logging" icon="file-lines">
    Get help adding debug logs:
    ```
    Add strategic console.log statements to debug this issue:

    @CurrentFile

    Focus on:
    - Function inputs/outputs
    - Conditional branches
    - Async operation states
    ```
  </Accordion>

  <Accordion title="Reproduce Reliably" icon="rotate">
    Create reproduction steps:
    ```
    This bug is intermittent. Help me:

    1. Create a minimal reproduction
    2. Identify triggering conditions
    3. Make it reproduce consistently
    4. Then fix it
    ```
  </Accordion>
</AccordionGroup>

## 🔧 Debug Workflow Templates

### Complete Debug Session

```
I'm debugging: [issue description]

Steps to reproduce:
1. [step 1]
2. [step 2]
3. [step 3]

Expected: [expected behavior]
Actual: [actual behavior]
Error: [error message if any]

Context:
@CurrentFile
@Terminal
@Diff (recent changes)

Please walk me through:
1. Understanding the issue
2. Locating the root cause
3. Implementing a fix
4. Adding tests to prevent regression
5. Documenting the fix
```

**Mode:** Agent | **Time:** 15-30 min

---

### Quick Fix Template

```
Quick bug fix needed:

Bug: [one-line description]
File: @File [path]
Line: [approximate line number]

Please:
1. Confirm the bug
2. Fix it
3. Explain the fix
```

**Mode:** Edit | **Time:** 2-5 min

## 📊 Common Error Patterns

### Null/Undefined Errors

```
Fix null/undefined errors in this code:

@CurrentFile

Please:
1. Add null checks where needed
2. Use optional chaining (?.)
3. Provide default values
4. Add TypeScript strictNullChecks if applicable
```

---

### Async/Await Errors

```
Fix async/await usage in this code:

@File [path]

Common issues to check:
1. Missing await keywords
2. Unhandled promise rejections
3. Incorrect async function declarations
4. Promise chain errors
```

---

### Event Loop Issues

```
Debug event loop/timing issues:

@CurrentFile

Check for:
1. Callback timing problems
2. SetTimeout/setInterval misuse
3. Missing async/await
4. Blocking operations
```
